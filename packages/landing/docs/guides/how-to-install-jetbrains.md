# How to install the vectors plugin for JetBrains IDEs

## Option 1: install script (recommended)

```sh
curl -fsSL https://github.com/hieudoanm/vectors/master/scripts/install.sh | bash -- --jetbrains
```

The script downloads `extension-jetbrains-vectors.zip` from the
[latest release](https://github.com/hieudoanm/vectors/releases/latest) into
`~/Downloads`.

## Option 2: manual download

1. Open the [downloads page](https://hieudoanm.github.io/vectors/downloads/) and
   download **JetBrains** under **Editor Extensions** —
   `extension-jetbrains-vectors.zip`.

## Installing the zip

1. Open **Settings/Preferences → Plugins**.
2. Click the **⚙** gear icon → **Install Plugin from Disk…**.
3. Pick the downloaded `extension-jetbrains-vectors.zip` and restart the IDE if
   prompted.

## Troubleshooting

- To update, repeat the download and **Install Plugin from Disk** again —
  JetBrains replaces the previous version.
