## vectors — latest build

A Rust CLI and library for vector data workflows: embeddings,
similarity search, and vector-store operations, with an MCP server for
agent integrations.

### Download

| Platform | Asset |
| --- | --- |
| Linux x86_64 | `vectors-x86_64-unknown-linux-gnu` |
| macOS Apple Silicon | `vectors-aarch64-apple-darwin` |
| Windows x86_64 | `vectors-x86_64-pc-windows-msvc.exe` |

### Quick start

```sh
vectors --help
vectors mcp serve
```
